Ascension Privacy Policy

Ascension — Rise of Man is a game published by K3D0. This policy covers the game as distributed in the Microsoft Store and on GitHub.

What the game collects

Nothing. The game has no accounts, no analytics, no advertising and no telemetry. It does not send anything about you or your computer to the publisher or to anyone else.

What stays on your computer

  • Your settings and launcher presets, in your user configuration folder.
  • Saved games, in your user data folder.
  • When you join a network game, the seat token for that server address, so that you can
  • rejoin the same seat.

You can delete these files at any time; uninstalling the game does not send them anywhere.

Network play

The game connects to the network only when you choose to. When you join a game it talks only to the server address you type in; when you host a game or run a server it accepts connections from the players you give a key to. The messages carry the game itself: the orders you give, the name you choose, chat messages and the state of the match. The person who runs that server can see what reaches it; the publisher runs no server and sees nothing.

Children

The game collects no personal information from anyone, children included.

Changes and contact

Changes to this policy are published with the game's source at https://github.com/alfu32/ascension. Questions can be asked through the project's issue tracker at https://github.com/alfu32/ascension/issues.
