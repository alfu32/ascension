# Task 65 — A computer opponent that wins when it should

Crates: `rom-ai`, `rom-sim` (the orders and queries listed below), `rom-mapgen`
(fair two-player starts), `rom-cli` (duel), docs; schema and seed only if a
listed order needs a row. Starts after task 64 (it changes `rom-sim` and
`rom-app`). Implementer: Claude (Opus).

## Why

Task 61 built armies, space play and `rom duel`, but over 100 seeds
`balanced:moderate` beat `balanced:easiest` only 27 times, lost 16, and 57
matches were draws (target: at least 90 wins and no draws inside the tick
limit). Its report (task 61 row in `STATUS.md`, `app/docs/computer-player.md`)
names the causes: both difficulties run the same economy; player 1 keeps a
strong start advantage (36 of 43 decided matches); matches stall (an economy
that still gets stuck on some starts; long stand-offs before siege arrives);
and nine simulation gaps.

## Build

1. **Difficulty that shows in the economy.** Easier levels think slower,
   spend fewer orders, make more second-best choices and react later in the
   economy too (worker assignment, build order, research), from
   `ai_difficulty` and profile weights — data, never names. Measure solo
   `ai-match` curves per difficulty and show they differ.
2. **Fair starts.** Two-player (and n-player) maps give every start equal
   land and room for its first gathering sites, in `rom-mapgen` (not only by
   redrawing in the duel). Keep the universe and planet hashes stable where
   possible; explain changes.
3. **No stalls.** Find and fix the remaining economy deadlocks; armies bring
   siege early enough to take a city; a match without a winner at the limit
   is a bug to explain.
4. **Simulation gaps from task 61.** `explore`, `patrol`, `guard` executed;
   stance as an order; a failure report for accepted orders that fail while
   running (no path, no slot) that a brain can read; cancel an own unfinished
   building; a reachability query; formation movement at the slowest speed.
   Garrisoning for healing and planets generated by the simulation instead
   of the host are optional: say if left out. Each with determinism tests.
